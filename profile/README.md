# CredRadar

**Thailand & Malaysia international schools — every fee, verified.**

CredRadar is an independent directory and fee-intelligence project for international schools in Thailand and Malaysia. Every tuition figure is published with its source and verification date; figures that cannot be verified are shown as not published, never estimated.

- Website: https://credradar.org
- Thailand fees report (data & citations): https://credradar.org/reports/thailand-international-school-fees/
- Malaysia: https://credradar.org/malaysia/
- Contact: hello@credradar.org
