# Security Policy

## Reporting a vulnerability

If you find a security issue in any CredRadar repository or on credradar.org, please email hello@credradar.org instead of opening a public issue. We aim to acknowledge reports within two working days.

## Scope

These repositories publish open data. Corrections to the data itself are handled under the corrections policy at https://credradar.org/corrections/ — please use that route for data issues rather than security reports.
